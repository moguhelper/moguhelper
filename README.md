# MoguHelper

![玩国际服，不用懂英语](docs/banner.png)

冒险岛怀旧服的**中文助手**，Mac 免费版。测试中，全部功能免费。

An unofficial, free Chinese helper for MapleStory Classic World on macOS. In development.

觉得好用，就点一下本页右上方的 **☆ Star**（要先登录 GitHub，免费）。

## 系统要求

| 项目 | 要求 |
|---|---|
| 电脑 | Apple 芯片的 Mac（M1 及以后）。**不支持 Intel Mac** |
| 系统 | macOS 26.0 或更新。**macOS 15 及更早不能用** |
| 内存 | 建议 16 GB，8 GB 没测过；文字识别忙时会占到约 1 GB |
| 硬盘 | 程序约 8 MB，另加系统的英译中翻译包（首次由系统下载） |
| 权限 | 只要“屏幕录制”；不要“辅助功能”“输入监控” |
| 网络 | 下载翻译包时要；之后识别、翻译都不用网络 |
| 游戏 | MapleStory Classic World 国际服（北美）Mac 客户端，英文界面；韩服和 Windows 不支持 |
| 游戏窗口 | 800×600 窗口模式测得最多；1024×768、1280×720、1366×768 没有逐项测完 |

实际测试过的机器：M4、16 GB、macOS 27.0.1。其他机型符合要求，但没有逐一试过。

## 功能

**看得懂**
- 聊天、喇叭、喊买喊卖当场翻成中文，缩写和黑话也翻
- 鼠标停在装备、物品上看中文说明
- 打开任务详情，写出中文标题、目标和大意；NPC 让你选的几项列出中文

**算得清**
- 每小时经验、多久升级；捡钱、买药、卖东西分开记账
- 掉落、杀怪数、药水用量、每张图的效率；换角色自动分开

**认得路**
- 走过的图、路过的 NPC 自动记下来，再去时画面上出箭头
- 打开任务，自己见过的人和地方直接带路；没去过的列出要找谁、去哪
- 导出 .mogu 和朋友互换

也可以导入自己有权使用的游戏资料，格式见 [docs/资料格式.md](docs/资料格式.md)。没去过、没人传过的地方指不了路。

## 不做什么
- 不读写游戏内存和文件，不抓包，不替你按键、点击
- 识别和翻译都在你的电脑上，不上传聊天、截图和任何游戏数据
- 不带游戏图片，不带地图、任务和物品资料库；只有翻译要用的名词，认出提示、考题用的少量短句，和自己整理的玩法提示

## 第一次打开
本程序没有苹果开发者签名，macOS 会拦一次：
1. 解压，把 MoguHelper 拖进“应用程序”，双击，提示无法验证时点“完成”（别点“移到废纸篓”）。
2. 打开“系统设置 → 隐私与安全性”，拉到下面“安全性”，点 MoguHelper 旁边的“仍要打开”，输入密码。
3. 再打开一次。只需要做一次。

第一次打开会引导你打开“屏幕录制”权限、下载系统的英文→中文翻译包。

## 自己编译
```bash
./build-app.sh dist && open dist/MoguHelper.app
```
