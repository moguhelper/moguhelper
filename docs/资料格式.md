# 游戏资料格式

MoguHelper 不带、不提供、不下载游戏资料，也不指定来源。你可以导入自己准备、自己有权使用的资料：菜单 →“任务和路线”→“查路线、查掉落”→“导入游戏资料…”。文件只存在你的电脑上。

文件名固定，内容是 JSON（UTF-8，最大 20 MB）。用不到的可以不给。下面的例子是编的。

| 文件 | 内容 |
|---|---|
| `Maps.json` | `{"maps":[…],"npcs":{"1":"名字"},"mobs":{"1":"名字"},"quests":[…]}` |
| `Mobs.json` | `{"mobs":{"名字":{"lv":1,"hp":10,"exp":1,"png":"base64"}},"spawns":{"地图编号":{"名字":[[x,y]]}}}` |
| `Quests.json` | `[{"id":1,"name":"名字","area":"地区","en":["说明"],"zh":["中文"],"zhName":"中文名"}]`，`zh` 和 `en` 一一对应 |
| `QuestNames.json` | `{"npc":["名字"],"mob":{"英文":"中文"},"item":{},"map":{},"titles":{}}` |
| `Items.json` | `{"items":[{"en":"英文","zh":"中文","cat":["Use"],"desc":[{"en":["…"],"zh":["…"]}]}]}` |
| `ItemSources.json` | 同程序自带的格式 |
| `ItemIcons.json` | `{"名字":{"png":"base64","color":[r,g,b],"cat":"Use"}}` |
| `MiniMaps.json` | `{"地图编号":"PNG 的 base64"}` |

地图：`{"id":1,"street":"街道","name":"名字","box":[左,上,右,下],"ret":回城到的图,"portals":[[目标图,x,y,类型]],"npcs":[[编号,x,y]],"mobs":[[编号,刷新点数]],"mini":[宽,高],"warps":[[入口x,入口y,出口x,出口y,类型]]}`。没有小地图时 `mini` 为 `[]`；`warps` 可省略。

任务（在 Maps.json 里）：`{"id":1,"start":接任务的NPC,"end":交任务的NPC,"mobs":[["名字",数量]],"items":[["名字",数量]],"level":10,"slevel":8,"meso":0,"exp":0}`，后四项可省略。
