不用懂英语

冒险岛怀旧服的中文助手。聊天、装备、任务当场变中文，经验金币自己记账，走过的路下次带你走。

免费下载 Mac 版需要 Apple 芯片（M1 及以后）和 macOS 26.0 以上。看完整要求
  1. 这是开着 MoguHelper 玩的样子左边是游戏，右边是 MoguHelper 的面板。往下滚，一处一处看。
  2. 画面上带路箭头直接画在游戏上：往哪走、进哪个门、还有几张图。走到了就告诉你“就在这张图”。
  3. 说明框当场变中文技能、装备、物品的说明，鼠标停上去就盖上中文，图标还在。
  4. 游戏里的任务追踪游戏自带的追踪框只有英文和数字。MoguHelper 读它，知道你打到哪了。
  5. 任务助手：接 → 做 → 交打什么、去哪打、交给谁，按顺序排好，打够了打 ✓。这张图就有要打的怪，就告诉你“就在这张图”。
  6. 经验、金币自己记账每小时多少经验、多久升级；打怪捡的、卖的、买的分开记；掉了什么、杀了几只，都只看屏幕上的数字。
  7. 全在游戏旁边不挡游戏画面，不碰游戏，不上传。

还能做什么

  • 走过的路记下来走过的图、进过的门、路过的 NPC 自动记下，下次直接带路。
  • 和朋友互传导出一个 .mogu 文件，朋友导入就能用你走过的路。
  • 任务卡1 到 30 级常见任务：找谁接、打什么、去哪打、交给谁。
  • 答题提示新手岛问答 NPC 出题时，提示该选哪个。
  • 药水和净收益喝掉多少药、花了多少钱，和赚的一起算净收益。
  • 换角色自动分开每个角色一份记录，切换时自动认出来。

不做什么

不碰游戏

不读写内存和文件，不抓包，不替你按键、点击。

不上传

识别和翻译都在你的 Mac 上，聊天和截图不外发。

不带资料库

没有游戏图片、地图、任务和物品大表，只有翻译用的名词、少量提示短句和自己整理的玩法提示。

不收钱

全部功能免费，源码公开，禁止商用。

能不能用

电脑
Apple 芯片的 Mac（M1 及以后）

macOS 26.0 或更新

实际测试过的机器：M4、16 GB、macOS 27.0.1。

怎么装

没有苹果开发者签名，第一次打开 macOS 会拦一次。只需要做一次。

  1. 下载、解压，把 MoguHelper 拖进“应用程序”。
  2. 双击，提示无法验证时点“完成”。
  3. 到“系统设置 → 隐私与安全性”，点“仍要打开”。
  4. 照着引导打开“屏幕录制”，下载系统翻译包。

喜欢就点颗星

点星不花钱，也不用懂代码。星多了，更多玩家能搜到它。

  1. 打开 GitHub 项目页，右上角点 Sign in 登录。
  2. 没有账号就点 Sign up，用邮箱免费注册一个。
  3. 回到项目页，点右上方的 ☆ Star。变成黄色的 ★ Starred 就好了。
